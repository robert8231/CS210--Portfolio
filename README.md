CS 210 Module Eight Journal – Portfolio Reflection

Project Summary: For my portfolio submission, I selected my Chada Tech Clocks project. This program displays two synchronized clocks, one in 12‑hour format and one in 24‑hour format, and allows the user to adjust the time through a menu system. It solves the problem of creating a functional, modular C++ program that handles time calculations accurately and presents clear output to the user.

What I Did Well: I organized the program into multiple files and wrote readable, well‑commented code. The modular structure made the program easier to maintain and matching industry standards.

Where I Could Improve: I could improve the input validation and streamline some of the time‑adjustment logic. These improvements would make the program more secure, efficient, and better prepared for real-life use.

Challenges and How I Overcame Them: The most challenging part was getting the time‑adjustment functions to work correctly without breaking the formatting. I overcame this by breaking the logic into smaller pieces, testing each function individually, and using debugging tools and course resources. These tools are now part of my support network for future projects.

Transferable Skills: This project strengthened skills such as modular programming, debugging, using header files, and designing programs that observe industry standards. These skills will transfer directly to future coursework and software development tasks.

Maintainability and Readability: I made the program maintainable by separating logic into functions and organizing the project into multiple files. I used descriptive variable names, consistent formatting, and comments to explain key sections of the code, making it easy to update or expand later.
